## Problem

The main product value is a percentage for the estimated chance that porcini are growing in a selected area on a selected day. The repository does not yet calculate that quantity. P5 generates synthetic scores from coordinates and dates. P4's published rules count matched conditions and its statistical benchmark ranks reported finds. Neither is a validated probability calculation.

The owner accepts experimental percentages for a companion product. This removes field validation as a release gate, but it still requires a stated calculation using real inputs, consistent dates and honest explanations. An implementing agent must not silently relabel a rule count or the P5 demo as a probability.

## Goal

Calculate versioned experimental estimates for the four-species porcini group on the national 500 m grid for today and the next seven days. Serve map and detail responses from the same completed result batch.

## Evidence and starting points

- [P4 benchmark](https://github.com/andreagrandi/micometeo/blob/master/reports/p4_benchmark.md) found useful timing evidence from earlier rain. The fitted weather-and-habitat model fell from 37 percent of finds in the top fifth on the test set to 24 percent on the final set. That is a ranking result, not a growth probability.
- [Rule configuration](https://github.com/andreagrandi/micometeo/blob/master/experiments/p4b_benchmark/config.toml) records the source and assumption behind each threshold. `src/micometeo/benchmark/models.py` provides reusable arithmetic, including rain from 30 to 8 days before.
- [P5 API](https://github.com/andreagrandi/micometeo/blob/master/apps/api/README.md) establishes bounded geographic requests and compression. Its synthetic scores, species selector, historical picker and reliability labels are not MVP requirements.
- `docs/product_prd.md`, "Percentage meaning and calculation", supersedes the earlier regional scope and compulsory field-validation recommendations. The later product decision must be explicit in each child.

The estimated event is visible porcini growing somewhere in the selected area on that day. It is not the visitor's chance of finding or collecting them. Whole percentages carry an experimental label. Missing required inputs produce an unavailable result, not zero percent.

## Acceptance criteria

- [ ] AC1: `docs/forecast_method.md` contains the exact formula, parameters, source assumptions, required inputs and worked examples. Tests reproduce those examples without live services.
- [ ] AC2: Batch tests prevent mixed versions, partial publication and changes to the previous completed result after a failed update.
- [ ] AC3: API tests show the map and area details agree on cell, target date, percentage and result-batch ID, including while a new batch is published.
- [ ] AC4: Responses expose actual source dates, input detail and missing reasons. They contain no synthetic P5 values or unsupported numerical accuracy claims.
- [ ] AC5: The calculation uses real weather and habitat across Italy. It does not require manual field validation, new observation collection or automatic learning.

## Boundaries

No new model competition, reopening of the already-used final benchmark set, observation publishing, species picker or historical playback. The exact percentage formula is work owned by #47, not a result already established by research. Public deployment and purchases remain outside the MVP.
